# Реализация различных криптографических алгоритмов на Python
Здесь будут выложены некоторые криптографические алгоритмы, которые удалось реализовать.
Алгоритмы разработаны в рамках лабораторной работы по дисциплине «Криптографические протоколы».

## 1. XTEA (eXtended Tiny Encryption Algorithm)
XTEA - симметричный блочный шифр, использующий:

- размер блока - 64 бита (8 байт);
- размер ключа - 128 бит (16 байт);
- разбиение ключа на 4 слова по 32 бита;
- 32 раунда шифрования;
- константу DELTA = 0x9E3779B9 (золотое сечение).

Реализация поддерживает шифрование и расшифрование текстовых данных с 
использованием UTF-8 и PKCS#7-подобного дополнения блоков.

### Возможности

На текущем этапе реализованы:

- шифрование текста с помощью XTEA;
- расшифрование шифротекста обратно в исходный текст;
- работа с UTF-8;
- разбиение данных на блоки по 8 байт;
- добавление и проверка padding;
- генерация случайного 128-битного ключа;
- ввод ключа в HEX-формате;
- ввод текстового ключа;
- проверка корректности ключа;
- преобразование ключа между bytes и четырьмя 32-битными словами;
- консольный интерфейс для работы с шифром.

### Работа с ключом

Программа поддерживает три варианта задания ключа:

Генерация случайного ключа.
Ввод ключа в HEX-формате.
Ввод текстового ключа.

Ключ XTEA должен иметь размер 128 бит (16 байт).

Пример HEX-ключа:

`00112233445566778899AABBCCDDEEFF`

Внутри программы ключ преобразуется в четыре 32-битных слова:

`00112233 44556677 8899AABB CCDDEEFF`

Для генерации ключей используется криптографически стойкий генератор случайных 
байтов Python `secrets`.

### Padding

Поскольку XTEA работает только с блоками размером 8 байт, 
перед шифрованием данные дополняются до размера, кратного размеру блока.
Используется схема, аналогичная PKCS#7.

Например, если до конца блока необходимо добавить 3 байта:
`03 03 03`

Если исходные данные уже занимают целое количество блоков, добавляется полный блок:
`08 08 08 08 08 08 08 08`

При расшифровании padding проверяется и удаляется.

### Структура проекта
`xtea.py`

Содержит класс XTEA, реализующий основной интерфейс шифрования:

cipher = XTEA(key)

encrypted = cipher.encrypt(text)
decrypted = cipher.decrypt(encrypted)

Внутри класса реализованы операции шифрования и расшифрования 
отдельных 64-битных блоков.

`utils.py`

Содержит вспомогательные операции:

- преобразование блоков между bytes и 32-битными словами;
- преобразование ключа;
- генерацию ключа;
- добавление padding;
- удаление padding;
- разбиение данных на блоки.

`main.py`

Предоставляет консольный интерфейс со следующими возможностями:

- выбор способа задания ключа;
- ввод текста;
- запуск шифрования;
- вывод ciphertext в HEX;
- расшифрование и вывод исходного текста.

### Пример использования

После запуска программы пользователь выбирает способ задания ключа.

Пример работы программы:
```
Алгоритм шифрования XTEA

Выберите способ задания ключа:
1. Сгенерировать ключ
2. Ввести HEX-ключ
3. Ввести текстовый ключ

После выбора ключа вводится текст:

Введите текст, который хотите зашифровать:
Hello, XTEA!

Программа выводит ciphertext в HEX и выполняет обратное расшифрование:

Hex-код текста: ...

Расшифрованный текст: Hello, XTEA!
```
