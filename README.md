# Реализация различных криптографических алгоритмов на Python
Здесь будут выложены некоторые криптографические алгоритмы, которые удалось реализовать.
Алгоритмы разработаны в рамках лабораторной работы по дисциплине «Криптографические протоколы».

## 1. XTEA (eXtended Tiny Encryption Algorithm)
XTEA - симметричный блочный шифр, использующий:

- размер блока - 64 бита (8 байт);
- размер ключа - 128 бит (16 байт);
- разбиение ключа на 4 слова по 32 бита;
- 32 раунда шифрования;
- константу DELTA = 0x9E3779B9 (золотое сечение).

Реализация поддерживает шифрование и расшифрование текстовых данных с 
использованием UTF-8 и PKCS#7-подобного дополнения блоков.

### Возможности

На текущем этапе реализованы:

- шифрование текста с помощью XTEA;
- расшифрование шифротекста обратно в исходный текст;
- работа с UTF-8;
- разбиение данных на блоки по 8 байт;
- добавление и проверка padding;
- генерация случайного 128-битного ключа;
- ввод ключа в HEX-формате;
- ввод текстового ключа;
- проверка корректности ключа;
- преобразование ключа между bytes и четырьмя 32-битными словами;
- консольный интерфейс для работы с шифром.

### Работа с ключом

Программа поддерживает три варианта задания ключа:

Генерация случайного ключа.
Ввод ключа в HEX-формате.
Ввод текстового ключа.

Ключ XTEA должен иметь размер 128 бит (16 байт).

Пример HEX-ключа:

`00112233445566778899AABBCCDDEEFF`

Внутри программы ключ преобразуется в четыре 32-битных слова:

`00112233 44556677 8899AABB CCDDEEFF`

Для генерации ключей используется криптографически стойкий генератор случайных 
байтов Python `secrets`.

### Padding

Поскольку XTEA работает только с блоками размером 8 байт, 
перед шифрованием данные дополняются до размера, кратного размеру блока.
Используется схема, аналогичная PKCS#7.

Например, если до конца блока необходимо добавить 3 байта:
`03 03 03`

Если исходные данные уже занимают целое количество блоков, добавляется полный блок:
`08 08 08 08 08 08 08 08`

При расшифровании padding проверяется и удаляется.



### Пример использования

После запуска программы пользователь выбирает способ задания ключа.

Пример работы программы:
```
Алгоритм шифрования XTEA

Выберите способ задания ключа:
1. Сгенерировать ключ
2. Ввести HEX-ключ
3. Ввести текстовый ключ

После выбора ключа вводится текст:

Введите текст, который хотите зашифровать:
Hello, XTEA!

Программа выводит ciphertext в HEX и выполняет обратное расшифрование:

Hex-код текста: ...

Расшифрованный текст: Hello, XTEA!
```

## 2. RSA (Rivest-Shamir-Adleman)

RSA - ассиметричный алгоритм шифрования, 
основанный на свойствах арифметики по модулю 
произведения двух простых чисел.

Алгоритм использует пару ключей:

Открытый ключ (e, n) - применяется для шифрования.

Закрытый ключ (d, n) - применяется для расшифрования.

### Генерация ключей

В реализации используются следующие этапы:

1. Генерация случайных кандидатов в простые числа с помощью модуля secrets.
2. Проверка кандидатов тестом Миллера - Рабина.
3. Вычисление модуля RSA:
`n = p * q`
4. Вычисление функции Эйлера:
`phi = (p - 1) * (q - 1)`
5. Использование открытой экспоненты `e = 65537`.
6. Вычисление закрытой экспоненты `d` с помощью расширенного алгоритма Евклида.

Закрытая экспонента должна удовлетворять условию:

`(e * d) % phi == 1`

Для генерации ключей используется класс RSA.

Пример создания объекта:

`rsa = RSA(bits=10)`

Параметр bits задает битовую длину генерируемых простых чисел `p` и `q`. 
Он не задает непосредственно длину модуля `n`, которая определяется 
произведением этих чисел.

### Шифрование текста

Перед шифрованием текст кодируется в UTF-8 и преобразуется в последовательность байтов.

Далее данные разбиваются на блоки. Размер блока выбирается с учетом модуля `n`, 
чтобы каждый блок можно было представить целым числом `m`, удовлетворяющим условию:

`0 <= m < n`

Каждый блок шифруется отдельно:

`c = power(m, e, n)`

Результаты шифрования сохраняются в виде последовательности целых чисел.

Для удобства представления и передачи шифротекст кодируется в Base64. 
Base64 является способом кодирования данных, а не дополнительным алгоритмом шифрования.

### Расшифрование текста

Расшифрование выполняется в обратном порядке:

1. Декодирование Base64 в байты шифротекста.
2. Восстановление отдельных зашифрованных блоков.
3. Расшифрование каждого блока с помощью закрытой экспоненты `d`.
4. Восстановление исходной последовательности байтов.
5. Объединение блоков и декодирование результата из UTF-8.

Для корректного восстановления данных также сохраняется исходная длина сообщения в байтах.

### Тест Миллера - Рабина

Для проверки кандидатов в простые числа используется вероятностный тест Миллера - Рабина.

Он позволяет с высокой вероятностью выявлять составные числа. 
При этом количество раундов влияет на вероятность ошибки, 
поэтому результат теста следует интерпретировать как проверку вероятной простоты, 
а не как абсолютное доказательство.

### Представление шифротекста

Шифротекст может быть представлен в виде Base64-строки вместо массива целых чисел. 
Это упрощает отображение результата в консоли, передачу через API и сохранение в 
текстовом файле.

Для восстановления блоков используется фиксированная длина байтового представления 
каждого зашифрованного числа, определяемая размером модуля `n`.

### Структура проекта

`xtea.py`

Содержит класс XTEA, реализующий шифрование и расшифрование блоков:

cipher = XTEA(key)

encrypted = cipher.encrypt(text)
decrypted = cipher.decrypt(encrypted)

Внутри класса реализованы операции шифрования и расшифрования 
отдельных 64-битных блоков.

`rsa.py`

Содержит класс RSA, реализующий генерацию ключей, шифрование и расшифрование:

rsa = RSA(bits)

encrypted = rsa.encrypt(text)
decrypted = rsa.decrypt(encrypted)

Внутри класса реализованы операции шифрования и расшифрования
отдельных блоков текста.

`utils.py`

Содержит вспомогательные операции:

- преобразование блоков между bytes и 32-битными словами;
- преобразование ключа;
- генерацию ключа;
- добавление padding;
- удаление padding;
- разбиение данных на блоки;
- расчет минимального размера блока;
- перевод байтов в число;
- перевод числа в массив байтов.

`math_utils.py`

Содержит математические функции:
- быстрое возведение в степень по модулю;
- расширенный алгоритм Евклида;
- тест Миллера-Рабина проверки простоты числа.

`main.py`

Предоставляет консольный интерфейс со следующими возможностями:

- выбор метода шифрования (RSA или XTEA)

При выборе алгоритма XTEA предлагается следующее:
- выбор способа задания ключа;
- ввод текста;
- запуск шифрования;
- вывод ciphertext в HEX;
- расшифрование и вывод исходного текста.

При выборе алгоритма RSA предлагается следующее:
- ввести текст, который необходимо зашифровать;
- вывод открытого и закрытого ключей;
- вывод шифротекста на экран.

## Ограничения безопасности

Проект реализован в учебных целях и демонстрирует принципы работы XTEA и RSA.

- Используемые в RSA небольшие простые числа не обеспечивают криптографическую стойкость;
- RSA без безопасного дополнения, например OAEP, не следует использовать для реального 
шифрования;
- Base64 не обеспечивает конфиденциальность данных;
- XTEA сам по себе не обеспечивает целостность и аутентичность сообщения;
- Закрытые ключи не следует публиковать или выводить в обычном режиме работы программы.

Для реальных приложений рекомендуется использовать проверенные криптографические 
библиотеки и современные схемы шифрования.
